# java-study

Java Silver 合格を目指す学習用リポジトリです。

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `chapter01/` | Javaの基本（クラス、mainメソッド、コンパイルと実行） |

章が進むごとに `chapter02/`、`chapter03/` … と追加していきます。

## 実行のしかた

```bash
cd chapter01
javac HelloWorld.java   # コンパイル（HelloWorld.class ができる）
java HelloWorld         # 実行
```

Java 11 以降なら、コンパイルを省略して `java HelloWorld.java` でも実行できます。
